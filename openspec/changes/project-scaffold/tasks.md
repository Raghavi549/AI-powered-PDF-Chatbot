Plain text extraction needs none of them. `pymupdf` 1.28.2 (2026-08-06) has **no dependencies**; a dry-run install in a clean venv confirmed it installs alone. Recommendation for C2: pin `pymupdf==1.28.2` and check it provides the page-text extraction C2 needs. Nothing was added to the application's requirements in C1.
